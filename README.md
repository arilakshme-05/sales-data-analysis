# Sales Data Analysis

A data analysis and visualization project in Python using Pandas and Matplotlib to analyze transaction records, identify top products, and track daily sales trends.

---

##  Project Overview

This project demonstrates foundational data analysis and visualization workflows using Python:
* **Pandas:** Handles data loading, cleaning, transaction calculations, and aggregation.
* **Matplotlib:** Generates visual charts for sales distributions and trend analysis.

---

##  Key Features

* **Data Cleaning:** Loads CSV dataset and handles missing or null values.
* **Feature Engineering:** Calculates total revenue per transaction (Quantity \times Price$).
* **Data Aggregation:** Groups metrics by product category and date.
* **Visual Analytics:** Generates bar charts (sales per product) and line graphs (daily sales trends).

---

##  Tech Stack

* **Language:** Python 3
* **Environment:** Google Colab / Jupyter Notebook
* **Libraries:** `pandas`, `matplotlib`
